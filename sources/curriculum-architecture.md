# FDE 课程架构

## 三条主线

- 业务：问题识别、需求访谈、方案范围、客户协作、交付验收、复盘复制。
- 技术：命令行、Git、Python、HTTP、JSON、API、数据、工作流、工具调用、日志和权限。
- 实训：选择一个可控项目，用输入、输出、人工确认、风险和验收验证能力。

## 主骨架

Guidance Book 的交付生命周期作为纵向骨架：FDE 认知 → 解决正确的问题 → 赢得客户 → 激活部署 → 使用与验收 → 续约/扩展 → 复制 → 指标与职业道德。

## 学习循环

按小块执行：

```text
讲 → 测 → 判断漏洞 → 再教 → 沉淀 → 练习 → 验收
```

课程结构可以随新资料调整，但每次调整必须记录原因和来源。练手项目可替换，不把招投标设为唯一项目。
