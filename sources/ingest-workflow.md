# 资料补充与入库流程

```text
登记
→ 初筛
→ 精筛
→ 去重
→ 蒸馏
→ 映射
→ 晋级或归档
```

## 初筛

检查是否与 FDE 学习目标相关、是否重复、是否有可追溯来源、是否有足够内容支持学习动作。只凭标题判断的资料标记为“待深读”。

## 精筛

将内容拆为事实、概念、程序、案例、观点、反例和待核对项。优先保留能转成练习、项目判断或验收证据的内容。

## 晋级规则

资料至少满足以下三项才进入课程核心：

1. 能对应一个 FDE 能力；
2. 有可追溯来源；
3. 能转成学习动作、项目任务或验收标准。

否则进入补充案例、待深读或观察档案。

## 更新记录

每次资料增量写明：日期、来源、变化、对应课程、状态、是否改变结构、下一步动作。每日破局新增内容先去重，不能直接覆盖课程正文。

## 与学习进度的分离

资料状态和学习状态必须分开记录：

| 资料状态 | 含义 |
|---|---|
| 已登记 | 已知道来源和位置 |
| 已入库 | 已进入资料池或认知模块 |
| 已蒸馏 | 已提取知识点、案例或方法 |
| 已挂接 | 已映射到课程或项目 |

| 学习状态 | 含义 |
|---|---|
| 未开始 | 学习者尚未学习 |
| 学习中 | 已开始但未完成练习 |
| 已理解 | 通过提问或复述检查 |
| 已练习 | 已提交实际产物 |
| 已验收 | 产物满足验收标准 |

“已入库”不等于“已学习”，“已学习”不等于“已掌握”。新资料进入系统时，先检查它对应的认知点、课程小节和已验收产物；如果已有相同能力证据，只做补充、对照或复习，不重复安排完整学习。
