# FDE 基础资料登记

> 本表登记当前基座的资料入口。它不等于所有资料已经被完全核对或全部写入课程。

| 名称 | 来源类型 | 入口 | 作用 | 当前状态 |
|---|---|---|---|---|
| 破局 FDE 主题 | 主要动态入口 | 通过 `@aipoju/breakout-cli` 按 FDE 等关键词查询 | 国内案例、实践反馈、行业动态和增量资料 | 持续更新；主题正文按需深读 |
| `FDE内容清单.md` | 本地破局索引 | 本地研发工作区生成，不作为公开包硬依赖 | 已检索主题的索引、阅读顺序和增量记录 | 本地维护；公开版只保留处理规则 |
| FDE Guidance Book | 公开书籍/仓库 | [xdash/FDE-the-Guidance-Book-of-Forward-Deployed-Engineer](https://github.com/xdash/FDE-the-Guidance-Book-of-Forward-Deployed-Engineer) | FDE 交付生命周期的纵向骨架 | 章节索引已映射；正文按需核对 |
| 公开 FDE 学习仓库、文章和报告 | 外部补充 | 每次登记具体 URL | 补充技术、案例、行业和职业信息 | 先初筛、精筛再进入课程 |
| 网络视频转写 | 用户获得的本地补充资料 | 本地工作区，不上传原始大文件 | 补充技术、案例和方法；转写后再蒸馏 | 当前待转写/待筛选 |
| 项目实训材料 | 用户或公开项目资料 | 具体项目目录或 URL | 用作学习验证，不替代事实来源 | 依项目单独登记 |

## 资料接入要求

新资料不得因“看起来权威”或“标题很吸引人”直接进入课程核心。先按 [`ingest-workflow.md`](ingest-workflow.md) 完成登记、筛选、去重和课程映射。
