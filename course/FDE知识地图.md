# FDE 知识地图

```text
破局 CLI 与外部资料
        ↓
资料筛选、蒸馏、来源审计
        ↓
FDE 专业知识
├─ 业务理解与问题定义
├─ 技术实现与数据处理
├─ 方案设计与项目推进
├─ 交付、验收与复盘
└─ 风险、权限、合规与职业伦理
        ↓
可替换项目实训
        ↓
作业、测试、输出、实战和迁移证据
```

## 能力到证据

| 能力域 | 证据 |
|---|---|
| FDE 边界 | 岗位和责任说明 |
| 问题定义 | 问题卡、访谈提纲 |
| 技术基础 | 可复现脚本、接口记录、错误记录 |
| 工作流 | 流程图、状态表、人工确认点 |
| AI 辅助 | 带来源的结构化输出和待审核项 |
| 交付验收 | 测试、审核、交付和复盘记录 |

## 学习循环

```text
输入 → 理解 → 沉淀 → 输出
                 ↓
       练习 → 实战 → 复盘 → 更新
```
