# 引导式学习与重复控制

## 学习入口

学习助手每次先读取课程进度、知识地图和资料增量记录，再推荐一个唯一的小节。不要把全部课程和视频列表交给学习者自行选择。

## 固定循环

```text
读取状态
→ 推荐一个小主题
→ 讲解
→ 提问
→ 判断知识漏洞
→ 必要时补教
→ 小练习
→ 作业产物
→ 验收
→ 更新学习状态
```

## 防重复规则

开始新资料或新视频前，检查：

1. 是否已经有相同或高度相似的认知点；
2. 对应课程小节是否已学习或验收；
3. 是否已有可验证作品；
4. 新资料是否带来新观点、反例、技术细节或冲突口径。

处理结果只能是：

- `补充证据`：不重新安排完整课程；
- `对照复习`：用于比较不同来源；
- `新增小节`：确实出现新的能力要求；
- `复做练习`：旧知识迁移到新项目；
- `归档不学`：重复或低价值资料。

## DSH 视频资料规则

DSH 可以继续转写和蒸馏，但每批输出必须带：视频标识、原始来源、认知点、对应课程、重复判断、证据等级和当前学习状态。视频批次完成后不自动启动学习，也不自动改变课程完成状态。

## 判断“是否学过”

只有同时满足以下条件，才把一个知识点记为已掌握：

- 能用自己的话解释；
- 能回答针对性问题；
- 能完成对应练习或项目产物；
- 产物通过验收。

仅有“看过视频”“有学习卡片”或“已入库”时，仍记为未开始或学习中。
